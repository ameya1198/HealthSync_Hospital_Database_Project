# HealthSync_Hospital_Database_Project


HealthSync is a comprehensive SQL-based project designed to manage hospital operations such as patient records, prescriptions, pharmacy inventory, and billing. This system streamlines data handling through advanced database functionalities like stored procedures, triggers, and complex queries.

** Note: The current version includes limited sample data and is primarily focused on demonstrating database structure and logic implementation.




** Project Components

HealthSync.sql: Defines the full database schema (tables, primary/foreign keys, constraints).

Functions.sql: Contains reusable functions for calculating costs, retrieving values, etc.

StoredProcs.sql: Includes stored procedures for patient check-in, billing, and inventory operations.

Triggers.sql: Sets up automated triggers to maintain data consistency (e.g., stock reduction on prescription).

Complex_Queries.sql: Provides reporting and analytical queries for insights like top medications and revenue trends.



** Features

Well-structured relational schema for hospital workflows.

Automated billing and inventory logic using procedures and triggers.

Reusable functions for operational efficiency.

Advanced queries for key analytics and reporting.





** Sample Use Cases

Generate daily revenue reports.

Identify top prescribed medications.

Track patients with frequent visits.

Automatically update pharmacy stock after a prescription is issued.
